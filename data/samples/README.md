# 합성 샘플 데이터 (실제 데이터 아님)

이 폴더의 CSV 는 `scripts/make_samples.py` 가 난수로 만든 **가짜 데이터**입니다. 제주데이터허브 실제 데이터의 컬럼 구조(레지스트리 기준)를 흉내 내어 에이전트의 동작을 시연·테스트하기 위한 것이며, 값은 실제 통계가 아닙니다. 실제 분석은 `.env` 에 프로젝트 키를 넣어 Open API 로 수집하거나 허브에서 내려받은 파일을 `data/raw/` 에 넣어 수행하세요.

- 생성 시드: 20261105
- 기간: 2024년(일 단위), 카드 2017~2018(월), 입도객 2018~2025(월), 관광지 2019~2024(월)
- 위치 데이터(와이파이 AP·전기차 충전소·관광 숙박업)는 읍면동 중심 좌표 주변에 난수로 배치한 가짜 위치입니다.
