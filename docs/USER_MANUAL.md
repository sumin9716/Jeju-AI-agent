# 사용자 매뉴얼 — 제주 데이터 길잡이

> 컴퓨터나 통계를 잘 몰라도 괜찮습니다. **궁금한 것을 우리말로 물어보면** 길잡이가 제주 데이터를 찾고, 계산하고, 그림과 보고서로 답해 줍니다.

## 1. 화면 열기

1. 제주빅데이터센터 PC 바탕화면의 **「제주 데이터 길잡이」** 아이콘을 더블클릭합니다. (아이콘이 없으면 담당자에게 문의하거나, 명령 프롬프트에서 프로젝트 폴더로 이동해 `streamlit run app.py` 를 입력합니다.)
2. 잠시 후 인터넷 브라우저에 화면이 열립니다. 열리지 않으면 주소창에 `http://localhost:8501` 을 입력합니다.

화면 구성:
- **왼쪽(사이드바)**: 상태 표시(API 키·모델), 데이터 현황, 예시 질문 버튼, 새 대화 시작, 산출물 내려받기
- **가운데**: 대화창. 아래쪽 입력칸에 질문을 적고 Enter

## 2. 질문하기

입력칸에 평소 말하듯 적으면 됩니다. 지역(읍면동), 기간, 비교하고 싶은 것을 함께 적으면 더 정확합니다.

| 이렇게 물어보세요 | 길잡이가 하는 일 |
|---|---|
| "애월읍은 주말과 평일 중 언제 사람이 더 많아?" | 유동인구 데이터로 요일별·연령대별 비교 |
| "노형동에서 카페를 열려고 해. 상권을 분석해줘" | 유동인구 + 음식점 인허가 + 카드 소비 결합 분석 |
| "비 오는 날 버스 손님이 얼마나 줄어?" | 기상 데이터와 정류소 승차 데이터 결합 |
| "2024년 감귤 등급별 가격 추세 보여줘" | 농산물 거래 통계로 추세 차트 |
| "외국인 관광객은 코로나 이후 얼마나 회복됐어?" | 입도객 통계 비교 |
| "이 내용을 보고서로 정리해줘" | 지금까지의 분석을 보고서 파일로 저장 |

예시 질문 버튼을 누르면 바로 실행됩니다. 한 번 답을 들은 뒤 **"연령대별로도 보여줘", "다른 동네와 비교해줘"** 처럼 이어서 물어볼 수 있습니다.

## 3. 답변 읽는 법

길잡이는 답을 다음 순서로 줍니다.
1. **결론** — 가장 중요한 한두 문장과 숫자
2. **근거** — 계산한 수치, 표, 차트
3. **데이터 출처와 기준** — 어떤 데이터(제주데이터허브 데이터명·번호)의 어느 기간을 썼는지
4. **주의할 점** — 데이터의 한계
5. **이어서 할 수 있는 질문**

답변 위의 **「🔍 분석 과정 보기」** 를 누르면 어떤 데이터를 불러왔고 어떤 계산을 했는지 단계별로 볼 수 있습니다(코드가 보이지만 읽지 않아도 됩니다). **「🧠 에이전트 판단 과정」** 은 길잡이가 왜 그렇게 분석했는지 요약입니다.

> ⚠️ **"합성 샘플 데이터"** 라는 표시가 있으면, 실제 제주 통계가 아니라 연습용 가짜 데이터로 계산한 것입니다. 실제 수치가 필요하면 담당자에게 제주데이터허브 연결(프로젝트 키)을 요청하세요.

## 4. 보고서와 파일 내려받기

- 보고서를 만들면 답변 아래에 **「📄 보고서 HTML 내려받기」, 「📝 보고서 Markdown」, 「🐍 재현 스크립트」** 버튼이 생깁니다.
- HTML 보고서는 인터넷 없이도 열리고, 차트를 마우스로 움직여 볼 수 있습니다. 보고서 끝에는 **데이터 출처·이용조건과 실행한 코드**가 그대로 들어 있어 나중에 같은 분석을 다시 할 수 있습니다.
- 파일은 프로젝트 폴더의 `outputs/reports/` 에도 저장됩니다.

## 5. 내려받은 파일로 분석하기

제주데이터허브에는 1,200종이 넘는 데이터가 있고, 그중 대부분은 파일(CSV/엑셀)로 내려받는 방식입니다.
1. 허브(https://www.jejudatahub.net)에서 원하는 데이터를 찾아 **다운로드** 합니다.
2. 받은 파일을 프로젝트 폴더의 **`data/raw`** 폴더에 넣습니다. (사이드바 「데이터 현황」에 파일 이름이 나타납니다)
3. "**○○ 파일을 불러와서 ~를 분석해줘**" 라고 물어봅니다. 파일 이름은 일부만 적어도 됩니다.

길잡이가 파일을 읽고 숫자·날짜 형식을 자동으로 맞춘 뒤, 구조 요약과 함께 분석을 진행합니다. 데이터 설명·수집 기간·이용조건은 허브의 데이터 상세 페이지를 함께 참고하세요.

## 6. 새로 시작하기

사이드바의 **「🧹 새 대화 시작」** 을 누르면 이전 대화와 데이터를 지우고 처음부터 시작합니다.

## 7. 자주 묻는 질문

**Q. 답이 느려요.** 데이터가 크면 1~3분 걸릴 수 있습니다. 화면 위 상태표시(단계 N…)나 명령줄의 "생각하는 중… 12초" 같은 표시가 움직이면 정상입니다. 관리자가 `.env` 의 `JEJU_AGENT_EFFORT` 를 `max` 로 두었다면 질문마다 몇 분씩 걸릴 수 있으니, 평소에는 `medium` 을 권합니다. 명령줄에서 멈추고 싶으면 Ctrl+C 를 누르세요. 그 질문만 취소되고 앞의 대화는 그대로 남습니다.

**Q. "API 키가 없습니다" 라고 나와요.** 담당자가 `.env` 파일에 키를 넣어야 합니다. (관리자 안내: README 참고)

**Q. 길잡이가 모른다고 해요.** 제주데이터허브에 그 데이터가 없거나 아직 등록되지 않은 경우입니다. 길잡이가 알려주는 데이터 이름과 번호로 허브에서 파일을 내려받아 `data/raw` 폴더에 넣으면(5장) 바로 분석할 수 있습니다.

**Q. 숫자를 믿어도 되나요?** 길잡이는 계산한 숫자만 말하도록 만들어졌고, 보고서에 계산 과정이 모두 남습니다. 다만 유동인구·카드 데이터는 통신사·카드사의 **추정치**이므로 "대략적인 경향"으로 읽는 것이 안전합니다. 중요한 결정에는 원자료와 담당자 확인을 함께 하세요.

**Q. 개인 정보가 나오나요?** 아니요. 모든 데이터는 읍면동·연령대 등으로 묶인 통계이며, 길잡이는 개인을 식별하는 정보를 다루지 않습니다.

## 8. 관리자용 요약
- 설치: `setup.bat`(Windows) / `./setup.sh` · 시작: `run.bat` / `./run.sh` (또는 `streamlit run app.py`) · 점검: `python -m jeju_agent.cli doctor`
- 키 설정: `.env` (`ANTHROPIC_API_KEY`, `JEJUDATAHUB_PROJECT_KEY`)
- 실제 데이터 연결: `jeju_agent/datahub/registry.yaml` 의 `api_id`, 또는 `data/raw/` 에 파일 저장
- Open API 일괄 점검: `python -m jeju_agent.cli data check-api` (센터·개인 PC 에서 실행, 결과를 보고 `rename` 보정). 보고서 끝의 '할 일'에 허브 프로젝트에 추가할 API, 다시 확인할 API 고유 ID, 최근 날짜 확인이 필요한 데이터가 정리됩니다.
- 로그: `outputs/traces/` (질문·도구 호출·결과 요약), 보고서: `outputs/reports/`
